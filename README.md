# Price Comparison Application

A web application that helps users search for products and compare their prices across multiple e-commerce platforms such as Amazon, Walmart, and eBay.This project was developed for the Software Development (IS-5200) course at Saint Louis University.
[Live Demo Link](https://price-comparison-v2.vercel.app/)

# Key Features
Product Search: A search bar allows users to search for products[cite: 14].
Price Comparison: Compares prices, ratings, and reviews from Amazon, Walmart, and eBay for each product.
Product Details: Users can view detailed product information, descriptions, and purchase links.
Wishlist: Users can add products to a wishlist [cite: 25] [cite_start]or remove them. The wishlist is saved in the browser using LocalStorage.
Responsive Design:** The website is designed to work smoothly across devices.

# Tech Stack
| HTML5 | Structure of the web pages |
| CSS3 | Styling and layout  |
| JavaScript (ES6+) |Dynamic content rendering  |
| Fake Store API | Fetching product data  |
| LocalStorage | Storing wishlist data  |
| Fetch API | Handling API requests |
